# ラフ仕様
## 機能概要
- ユーザーは画面にhtmlファイルをドラッグ＆ドロップする
- ドラッグ＆ドロップされたhtmlファイルが表示可能かどうかをチェックする
- 表示可能であれば、画面遷移してそのhtmlを表示する
- html単位でユニークなURLを発行する
- URLをコピーできるボタンを配置する
- htmlファイルをドラッグ＆ドロップする画面（ログイン後に表示される初期画面）へ戻るボタンを配置する
- 初期画面にはユーザーが過去にドラッグ＆ドロップしたhtmlの一覧がカード形式で画面下部に表示される。表示順序は新しいもの順
- 初期画面にはログインユーザーのIDと名前が表示する
- カードにはリンクプレビューを表示する
- htmlファイルをドラッグ＆ドロップしたユーザーはそのhtmlファイルのオーナーである
- オーナーは初期画面のカードからhtmlファイルの削除ができる
- オーナー以外はhtmlファイルのURLをクリックしたとき、そのhtmlファイルが閲覧できる
- 閲覧にはログインが必須である
- オーナー以外はhtmlを閲覧することしかできない
